# Conquer Health — submission driver

OpenAI-compatible multi-turn conversation driver. Every answer is generated by
Lunit L2 (`Lunit/L2-preview`) through the two-stage retrieval/generation harness
described in the Lunit FM guide.

    docker build -t submission .
    docker run --rm -p 8000:8000 submission
    curl localhost:8000/v1/models

    system/intake.py       stage 0 — rewrite, turn context, deterministic routing
    system/retrieval.py    stage 1 — source-bounded MCP evidence loop
    system/generation.py   stage 2 — original history + evidence -> answer
    system/config.py       runtime knobs
    submission/app.py      the service (stateless; port 8000)

No benchmark data, rubric text, or per-item tuning is present in this image.
