# Submission runtime

The container serves an OpenAI-compatible API on port 8000. Its final answer is
always generated by Lunit L2; MCP retrieval only supplies bounded reference data.

Provide `LUNIT_FM_API_KEY` as a runtime secret. Do not put its value in the
Dockerfile, an image layer, or Git. The L2 and MCP URLs have Lunit-hosted defaults
and can be overridden with `LUNIT_FM_API_URL` and `LUNIT_MCP_URL`.

Example local run after building the image:

```powershell
docker run --rm -p 8000:8000 --env-file .env conquer-health
```

The service performs no downloads at runtime. Building the image still requires
access to the Python base image and packages listed in `requirements.txt` unless
the evaluator supplies an offline image/package cache.

Run the synthetic tests after installing the submission requirements:

```powershell
python -m pip install -r submission/requirements.txt
python -m unittest discover -s tests -v
```
